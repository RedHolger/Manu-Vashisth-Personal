# Synthetic incident fixtures — P12 IncidentReplay

Every file in this directory is generated by `scenarios.py` from a fixed
scenario table. **There is no real incident, no real host and no real user
here.** All IP addresses come from ranges reserved for documentation and
benchmarking: RFC 5737 `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`
and RFC 2544 `198.18.0.0/15`.

Regenerate (byte-identical; no clock reading and no randomness involved):

```sh
python3 -B -c "import scenarios; scenarios.write_fixtures()"
```

## Layout

- `<scenario-id>/audit.jsonl` — application audit log, JSON Lines, UTC
  (`+00:00`) timestamps, monotonic per-scenario `seq`.
- `<scenario-id>/edge-syslog.log` — RFC 3164-style `key=value` forwarder
  lines. For `m01`/`m02`/`m03` the forwarder writes `+09:00` and its clock
  runs 7 s fast; for `b01` it writes UTC and is synchronized. Some events
  exist *only* here (the edge VPN concentrator is their sole source).
- `<scenario-id>/baseline.json` — asset-owner configuration (known source IPs
  and normal egress per actor). Detector *input*, never a label.
- `adversarial/` — deliberately broken sources: naive timestamps with and
  without a declared host offset, a same-id semantic conflict, and a same-id
  timestamp disagreement beyond the clock-skew tolerance.
- `manifest.json` — sha256, byte size and record count for every file above.

No PCAP, no packet captures, no production data, no personal data.
