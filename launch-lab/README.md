# LaunchLab — discovery to decision, honestly labeled

Take a developer tool from opportunity to launch decision without inventing
customers: opportunities ranked on real artifacts or explicit HYPOTHESIS
labels, an instrumented dry-run pilot (ordered, time-windowed events; tests
kept strictly separate from users), message-comprehension testing (never
called conversion), publishing gated on named authorization (nothing
published), and a memo that keeps conflicting feedback and recommends
STOP/wait at zero users. Pure Python, stdlib only.

## Run it

```sh
python3 -B -m unittest discover -p 'test_*.py'   # 19 tests
```

Recorded: 2 evidenced + 2 hypothesis opportunities; out-of-order/late events
excluded with reasons; uplift/quote/revenue claims raise without real-user
evidence. No interviews ran, no users measured, no revenue exists — the
audience needs are hypotheses until real people are involved.

## Limits

Portfolio-internal evidence proves buildability, not demand. The memo's
majority rule is a placeholder for judgment.
