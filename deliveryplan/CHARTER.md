# DeliveryPlan Charter (synthetic training scope)

Objective: ship a fictional payments launch (ledger, settlement batch, drill)
safely and observably.

In scope: API design, ledger build, risk rules, settlement batch, dashboard,
docs, rollback drill. Out of scope: real money movement, production access,
regulatory approval, vendor contracts.

Milestones: M1 code freeze (exit: settlement + dashboard done, drill scheduled).
Stakeholders: Platform/AO (lead), Risk/BK (reviewer), UI/CM (build).

This charter governs synthetic demo data only. No employer programme is
described or implied.
